# Engineering Invariants

- Never fabricate missing data.
- Every `Finding` requires evidence and an authoritative citation.
- Reproduction never reads `Finding`.
- Reproduction triggers derive only from `Environment` and `Signature`.
- Never silently substitute environment components.
- Never claim a failure was reproduced without executing its trigger and observing the result.
- Unknown and insufficient evidence are valid outcomes.
- Verify current WordPress Playground APIs against official documentation before implementation.
